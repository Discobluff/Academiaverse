# Setup instructions

## Backend ([Java Spring Boot](https://spring.io/projects/spring-boot))

### Installation

- Requirements:
  - Java 21
  - Gradle 7.5+

### Execution

Go to `src/backend`

On Linux:
```
./gradlew bootRun
```

On Windows:
```
gradlew.bat bootRun
```

### Tests

In `[src/backend]/src/test/java/com/academiaverse/`
